# SKILLX - Top-Tier Campus & Freelance Marketplace

SKILLX is a modern, responsive web application connecting talented student freelancers and vetted software engineers with clients and campus initiatives.

## 🌐 Pages & Features
1. **Landing & Hire Talent** (`index.html` / `skillx.html`) - Platform showcase, popular skill cards, and 3-step workflow.
2. **Find Work & Gigs** (`find-work.html`) - Live project feed, budget listings, and 6 specialization categories.
3. **Authentication & Campus Sign In** (`login.html`) - Tabbed Sign In / Create Account system with verified student badge.
4. **Step 1: Professional Info** (`profile-creation.html`) - Avatar upload, headline, experience levels, and technical skill categories.
5. **Step 2: Portfolio & Links** (`profile-creation-step-2.html`) - Featured projects, social URLs, and resume upload dropzone.
6. **Step 3: Availability & Preferences** (`profile-creation-step-3.html`) - Availability status cards, hourly rate range, and timezone sync.
7. **Why Us & Vetting Pipeline** (`why-us.html`) - 4-Stage Vetting Funnel, candidate scorecard, and head-to-head comparison matrix.

## 🛠️ Tech Stack
- **HTML5**: Semantic tags, accessibility (a11y), clean structure
- **CSS3**: CSS Variables (custom design system), Flexbox, CSS Grid, animations
- **Vanilla JavaScript**: Interactive tabs, toggles, file previewers, and dynamic forms
